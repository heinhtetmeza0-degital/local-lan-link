# Local Connect

Create a clean, modern, and lightweight social media web application inspired by Facebook. The app will be self-hosted on a Local Area Network (LAN) without internet dependency.

​Key Features & UI Requirements:

 ​Authentication (Local LAN friendly):

​Simple Sign Up / Login using Username and Password (No email verification or SMS OTP required).

​User Profile setup (Display Name, Profile Picture upload, and Bio).

 ​Main Feed:

​Create Post section: Text posts and Image/Video attachments.

​Feed displaying posts from all users with timestamps.

​Like/React button and Comment section under each post.

 ​Real-time / Interactive Elements:

​Simple notifications tab for post likes and comments.

​A search bar to find other users on the network.

 ​User Profile Page:

​Display user details, uploaded posts, and photo gallery.

 ​Technical Guidelines:

​Built with React, Tailwind CSS, and Lucide Icons for UI.

​Keep the architecture simple, clean, and optimized for smooth performance on local servers (Node.js/PocketBase compatible).

​Mobile-responsive design (looks like a native app on mobile browsers)."
